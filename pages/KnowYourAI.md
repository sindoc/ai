- The **KnowYourAI** framework is an open framework for mapping AI use cases and scenarios to risk profiles via a structured glossary.
- ## Features
	- [[Human-AI Relationships Glossary]] — five AI roles, each with an inherited risk tier
	- [[AI Governance___Tools___Bias Detector]] — gender, age, and other bias detectors
	- [[AI Governance___Policies]] — AI use case documentation and monitoring policies
	- Mapping of risks, policies, datasets, data domains, and data products for industry use cases
