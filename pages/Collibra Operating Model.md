- **Collibra** is the data governance platform whose operating model defines the five core [[Asset Codes]] that form the base of this graph's type hierarchy.
- The type hierarchy in this graph is an **extension** of Collibra's operating model, not a replacement.
- To import or export concepts to/from Collibra, use the Collibra CSV format. Transformation tools:
	- [[SilkPage]] — file transformation between Markdown, EDN, XML, CSV (Collibra format)
	- [[Singine]] — asset code registry and subscriber/import pipeline
