- **SilkPage** is a page/site builder component available at `~/ws/silkpage`.
- In the context of this graph, SilkPage is used for **file transformation** between:
	- Logseq Markdown (`.md`)
	- EDN (Logseq/Datomic format)
	- XML / RDF
	- Collibra CSV (for import into [[Collibra Operating Model]])
